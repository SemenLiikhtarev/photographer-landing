# Сайт свадебного и семейного фотографа с админ-панелью

Одностраничный сайт фотографа Артёма Акимова (Москва) на чистом HTML, CSS и JavaScript — без фреймворков, сборки и зависимостей. В комплекте идёт админ-панель: она позволяет загружать фотографии в галерею, менять цены и контакты, а публичная страница подхватывает изменения автоматически.

## Возможности

### Публичная страница

- Семантическая HTML5-разметка, `lang="ru"`, skip-link, доступность с клавиатуры.
- Адаптивная вёрстка: mobile-first, брейкпоинты 480 / 768 / 1024 / 1280 px.
- Мобильное меню с блокировкой скролла, закрытием по `Esc` и клику вне меню.
- Галерея с фильтрами «Все / Свадьбы / Семьи / Дети» и CSS-grid мозаикой.
- Лайтбокс: стрелки, клавиатура, свайп через Pointer Events, возврат фокуса.
- Ленивая загрузка изображений, `srcset`/`sizes`, явные `width`/`height` — без CLS.
- Анимации появления блоков с поддержкой `prefers-reduced-motion`.
- Слайдер отзывов с автопрокруткой, паузой при наведении и фокусе.
- Форма заявки: валидация, согласие на обработку данных, honeypot и понятные состояния отправки.
- SEO-мета, Open Graph, favicon в виде inline SVG.
- Дизайн-система: палитра `#faf8f5` / `#1f1d1b` / `#c08573`, Playfair Display + Inter.

### Админ-панель

- Вход по паролю (по умолчанию `admin2025`).
- Загрузка фотографий с автоматическим сжатием до 1200 px по длинной стороне.
- Категория и alt-описание для каждого фото, изменение порядка, удаление.
- Статистика по количеству фотографий и категориям.
- Редактирование трёх тарифов: название, цена, описание, список «что входит».
- Редактирование контактов: город, телефон, email, профиль ВКонтакте.
- Сброс галереи, цен и контактов к исходным значениям.
- Экспорт и импорт `data.json`, экспорт HTML-разметки галереи.
- Живая синхронизация с открытой страницей сайта через `storage`-событие.
- Приём заявок с формы в Excel-файл на Яндекс Диске через облачную функцию.
- Проверка подключения и тестовая заявка в админке.

## Быстрый старт

Требуется только [Node.js](https://nodejs.org) — для локального сервера. Сборка не нужна.

### Windows

Дважды запустите `start-server.bat`. Откроется админка по адресу:

```text
http://localhost:8000/admin.html
```

### macOS / Linux / вручную

```bash
node server.js
```

Если порт 8000 занят, сервер автоматически выберет следующий свободный и напишет адрес в консоль.

### Просмотр сайта

```text
http://localhost:8000/
```

> Важно: открывайте сайт и админку по `http://`, а не как файлы `file://`. Браузер делится `localStorage` только между страницами одного адреса — так изменения из админки гарантированно попадают на сайт.

## Как пользоваться админкой

1. Откройте `http://localhost:8000/admin.html`.
2. Войдите с паролем `admin2025`.
3. **Галерея** → «Добавить фото»: выберите изображение, категорию и alt-описание.
4. **Цены** → измените стоимость, описание и список услуг → «Сохранить цены».
5. **Контакты** → обновите город, телефон, email и ВК → «Сохранить контакты».
6. Откройте или обновите сайт — данные подставятся автоматически.

Пароль хранится в исходниках (`admin.html`, константа `PASSWORD`) и предназначен только для демонстрационной защиты. Для реального ограничения доступа нужен бэкенд или serverless-функция.

### Где хранятся данные

| Ключ `localStorage` | Содержимое |
| --- | --- |
| `akimov_photos` | Массив фотографий: `src`, `category`, `alt`, размеры, `span` |
| `akimov_pricing` | Тарифы и их описания |
| `akimov_contacts` | Город, телефон, email, ВК |
| `akimov_admin` (`sessionStorage`) | Флаг входа в админку |

Данные привязаны к браузеру и устройству. Чтобы изменения увидели все посетители, экспортируйте `data.json` и положите его рядом с `index.html` на хостинге.

## Сбор заявок в Excel на Яндекс Диске

Схема:

```text
Форма на сайте → Yandex Cloud Function → API Яндекс Диска → Заявки.xlsx в папке
```

Почему нужна функция: браузер не может писать в Яндекс Диск по одной ссылке на папку. Для записи нужен OAuth-токен, а хранить его в открытом JavaScript нельзя — токен получил бы любой посетитель. Поэтому токен лежит в переменных окружения небольшой облачной функции, а сайт знает только её адрес.

Без настройки функции сайт работает как обычно, но форма честно сообщает, что приём заявок не подключён, и предлагает написать в ВК или на почту.

### 1. Создайте папку на Яндекс Диске

1. Откройте [Яндекс Диск](https://disk.yandex.ru) и создайте папку, например `Заявки`.
2. Зайдите в неё и скопируйте адрес из строки браузера:

   ```text
   https://disk.yandex.ru/client/disk/Заявки
   ```

   Это обычный адрес папки, а не публичная ссылка. Он нужен только для кнопки «Открыть папку» в админке.

3. Не делайте папку публичной и не вставляйте в настройки ссылку вида `https://disk.yandex.ru/d/...`: по публичной ссылке таблица с телефонами и почтами клиентов будет доступна любому.

Путь для функции — `disk:/Заявки`. Для вложенной папки: `disk:/Фотограф/Заявки`.

### 2. Получите OAuth-токен Яндекс Диска

1. Откройте [создание приложения Яндекс OAuth](https://oauth.yandex.ru/client/new).
2. Заполните:
   - **Название** — любое, например `Сайт фотографа`;
   - **Платформа** — «Веб-сервисы»;
   - **Redirect URI** — `https://oauth.yandex.ru/verification_code`;
   - **Доступ к данным** — «Яндекс Диск», права на чтение и запись (`cloud_api:disk.read`, `cloud_api:disk.write`).
3. Сохраните приложение и скопируйте **ClientID**.
4. Откройте в браузере (подставьте свой ClientID):

   ```text
   https://oauth.yandex.ru/authorize?response_type=token&client_id=ВАШ_CLIENTID
   ```

5. Подтвердите доступ. В адресной строке появится `#access_token=...` — скопируйте значение токена. Оно понадобится на следующем шаге.

Токен — секрет. Не коммитьте его, не вставляйте в `yandex-config.js`, `admin.html` или `index.html`. Если токен попал в репозиторий или переписку, отзовите его в настройках Яндекс ID и получите новый. Срок жизни токена не бессрочный: при ответе функции `401` получите новый и обновите переменную окружения.

### 3. Создайте функцию в Yandex Cloud

1. Откройте [Yandex Cloud Functions](https://console.yandex.cloud/functions) и создайте функцию, например `wedding-requests`.
2. Создайте версию:
   - **Среда выполнения** — Node.js 20 (подойдёт и 18);
   - **Точка входа** — `index.handler`;
   - **Таймаут** — 20 секунд;
   - **Память** — 256 МБ;
   - **Код** — вставьте содержимое файла [`yandex-function/index.js`](yandex-function/index.js) (зависимостей нет, устанавливать ничего не нужно);
   - **Переменные окружения**:

     ```text
     YANDEX_DISK_TOKEN=полученный_токен
     YANDEX_DISK_FOLDER=disk:/Заявки
     YANDEX_DISK_FILE=Заявки.xlsx
     ALLOWED_ORIGINS=https://semenliikhtarev.github.io,http://localhost:8000
     ```

     В `ALLOWED_ORIGINS` перечислите origins без пути. Для GitHub Pages это `https://semenliikhtarev.github.io`; для локальной проверки — `http://localhost:8000`.
3. Сделайте функцию публичной: в настройках функции включите «Публичная функция» (или выполните `yc serverless function allow-unauthenticated-invoke wedding-requests`).
4. Скопируйте URL функции вида:

   ```text
   https://functions.yandexcloud.net/d4e1234567890
   ```

Через CLI то же самое можно сделать так:

```bash
yc serverless function create --name wedding-requests
yc serverless function version create \
  --function-name wedding-requests \
  --runtime nodejs20 \
  --entrypoint index.handler \
  --memory 256m \
  --execution-timeout 20s \
  --source-path ./yandex-function \
  --environment YANDEX_DISK_TOKEN=... \
  --environment YANDEX_DISK_FOLDER=disk:/Заявки \
  --environment YANDEX_DISK_FILE=Заявки.xlsx \
  --environment ALLOWED_ORIGINS=https://semenliikhtarev.github.io
yc serverless function allow-unauthenticated-invoke wedding-requests
```

### 4. Заполните `yandex-config.js`

```js
window.YANDEX_DISK = {
  folderUrl: "https://disk.yandex.ru/client/disk/Заявки",
  endpoint: "https://functions.yandexcloud.net/d4e1234567890",
  fileName: "Заявки.xlsx",
};
```

- `folderUrl` — адрес папки для кнопки в админке. Не публичная ссылка `/d/...`.
- `endpoint` — URL функции из предыдущего шага.
- `fileName` — должно совпадать с `YANDEX_DISK_FILE` в функции.

Закоммитьте и запушьте файл. На GitHub Pages изменения появятся после сборки.

### 5. Проверьте

1. Откройте админку → **Заявки**.
2. Нажмите **«Проверить подключение»** — должна появиться зелёная надпись о связи с функцией.
3. Нажмите **«Отправить тестовую заявку»** и подтвердите. В папке появится `Заявки.xlsx` со строкой «Тестовая заявка».
4. Отправьте заявку с сайта. Строка добавится в тот же файл.

### Что внутри таблицы

Файл создаётся автоматически при первой заявке. Колонки:

| № | Получена (МСК) | Имя | Телефон | Email | Дата съёмки | Тип съёмки | Сообщение | Страница |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |

Особенности:

- Новые строки дописываются в существующий файл, старые не перезаписываются.
- Если файл удалить, он создастся заново с заголовком.
- Если файл повреждён или это не XLSX, функция сохранит рядом резервную копию и создаст новый.
- Форматирование, которое вы вручную сделали в Excel, сохраняется; новые строки могут быть без ваших дополнительных стилей.
- Одновременные заявки обрабатываются по очереди в рамках одного экземпляра функции; при очень большом потоке возможна редкая потеря строки. Для свадебного сайта это не критично.

### Безопасность и ограничения

- Endpoint функции публичный: его может вызвать любой. Защита — honeypot-поле, серверная валидация и лимит 30 заявок за 10 минут с одного IP. Для серьёзной защиты добавьте Яндекс SmartCaptcha или Cloudflare Turnstile.
- `ALLOWED_ORIGINS` ограничивает вызовы из браузеров, но не является полноценной защитой от прямых запросов.
- Токен хранится только в переменных окружения функции. Не добавляйте его в клиентский код.
- В таблице персональные данные. Не публикуйте папку, не давайте ссылку на файл и удаляйте старые заявки, когда они больше не нужны.
- Форма собирает только имя, телефон, email, дату, тип съёмки и сообщение; согласие на обработку данных обязательно.

### Если не работает

| Симптом | Что проверить |
| --- | --- |
| `401` | Токен истёк или отозван — получите новый и обновите `YANDEX_DISK_TOKEN`. |
| `404` | Путь в `YANDEX_DISK_FOLDER` не совпадает с папкой на Диске. |
| Ошибка CORS в консоли | Добавьте origin сайта в `ALLOWED_ORIGINS` (без пути) и пересоздайте версию функции. |
| `500` | Откройте логи функции в Yandex Cloud — там будет причина. |
| Файл не появляется | Функция пишет по пути из `YANDEX_DISK_FOLDER`, а ссылка в админке — только для перехода в папку. |
| Форма пишет «приём заявок не подключён» | Пуст `endpoint` в `yandex-config.js` или страница закеширована. |

## Публикация на GitHub Pages

1. Запушьте репозиторий на GitHub.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch** → ветка `main` → папка `/ (root)`.
4. Сохраните настройки и дождитесь публикации.

После деплоя админка доступна по адресу `https://<username>.github.io/<repo>/admin.html`.

Чтобы обновления из админки увидели все посетители:

1. Внесите изменения в админке на опубликованном сайте.
2. Откройте **Публикация → Скачать data.json**.
3. Замените файл `data.json` в репозитории скачанным и сделайте коммит.

Пока `data.json` нет, сайт использует фотографии и тексты, зашитые в `index.html`. Файл опционален: без него всё тоже работает, просто изменения остаются в браузере владельца.

Чтобы проверить, как обновлённый сайт выглядит для нового посетителя, откройте его в приватном окне — там нет данных из `localStorage` вашей админки.

### Другие статические хостинги

Проект подходит для Netlify, Vercel, Cloudflare Pages, GitHub Pages и любого обычного статического хостинга: достаточно загрузить файлы репозитория. Для сайта серверная часть не требуется; отдельная облачная функция нужна только для записи заявок в Excel на Яндекс Диске.

## Формат `data.json`

```json
{
  "photos": [
    {
      "id": 1,
      "src": "img/image (1).jpeg",
      "category": "weddings",
      "alt": "Свадебная церемония в Москве",
      "width": 1024,
      "height": 1024,
      "span": 34
    }
  ],
  "pricing": {
    "love-story": {
      "name": "Love-story",
      "price": "12 000 ₽",
      "desc": "Описание тарифа",
      "includes": ["1–2 часа съёмки", "40–60 обработанных фото"]
    }
  },
  "contacts": {
    "city": "Москва",
    "phone": "+7 (900) 000-00-00",
    "email": "hello@example.com",
    "vk": "https://vk.com/username"
  }
}
```

Фотографии, загруженные через админку, хранятся в `src` как base64 (`data:image/jpeg;base64,...`). Это позволяет работать без бэкенда, но увеличивает размер `data.json`.

## Настройка

- **Цвета и типографика** — CSS-переменные в начале `style.css`.
- **Шрифты** — подключение Google Fonts в `index.html` и `admin.html`.
- **Пароль админки** — константа `PASSWORD` в `admin.html`.
- **Исходные фото, цены и контакты** — константы `DEFAULT_PHOTOS`, `DEFAULT_PRICING`, `DEFAULT_CONTACTS` в `admin.html`.
- **Портрет фотографа** — замените `image.jpeg`.
- **Фотографии галереи** — замените файлы в `img/` или загрузите новые через админку.
- **Приём заявок** — `folderUrl` и `endpoint` в `yandex-config.js`; токен, путь к папке и `ALLOWED_ORIGINS` — в переменных окружения функции (см. раздел «Сбор заявок в Excel на Яндекс Диске»).
- **Имя Excel-файла** — `fileName` в `yandex-config.js` и `YANDEX_DISK_FILE` в функции должны совпадать.

## Ограничения

- `localStorage` ограничен примерно 5 МБ на домен — обычно это 20–25 сжатых фотографий.
- Изменения в админке по умолчанию видны только в том браузере, где их внесли. Для публикации всем посетителям нужен экспорт `data.json`.
- Пароль админки хранится на клиенте и не является полноценной защитой.
- Приём заявок работает после настройки Yandex Cloud Function. Без неё форма показывает сообщение и контакты для прямой связи, а не имитирует отправку.
- Публичный endpoint функции может получать спам; встроены honeypot, валидация и лимит запросов, для сильной защиты нужна капча.
- OAuth-токен Яндекс Диска может истечь — тогда заявки перестанут записываться, пока вы не обновите `YANDEX_DISK_TOKEN` в функции.
- Excel-файл с заявками содержит персональные данные: не делайте папку публичной и удаляйте старые заявки.
- Публичная часть не требует сборки и работает на статическом хостинге; `server.js` нужен только для локальной проверки, а функция приёма заявок — только для формы.

## Доступность и производительность

- Контраст текста и элементов управления, видимый `focus-visible`.
- Кликабельные области не меньше 44×44 px.
- ARIA-атрибуты для меню, табов, лайтбокса, слайдера и форм.
- Уважение `prefers-reduced-motion`.
- Ленивая загрузка, `decoding="async"`, фиксированные размеры изображений.
- Отсутствие сторонних JS-библиотек и сборщиков.

## Лицензия и контент

Код проекта можно свободно использовать и адаптировать. Фотографии и текстовые материалы принадлежат их владельцу — перед публикацией замените демонстрационные данные на реальные.
