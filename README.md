# Сайт свадебного и семейного фотографа с админ-панелью

Одностраничный сайт фотографа Артёма Акимова (Москва) на чистом HTML, CSS и JavaScript — без фреймворков, сборки и зависимостей. В комплекте идёт админ-панель: она позволяет загружать фотографии в галерею, менять цены и контакты, а публичная страница подхватывает изменения автоматически.

## Возможности

### Публичная страница

- Семантическая HTML5-разметка, `lang="ru"`, skip-link, доступность с клавиатуры.
- Адаптивная вёрстка: mobile-first, брейкпоинты 480 / 768 / 1024 / 1280 px.
- Мобильное меню с блокировкой скролла, закрытием по `Esc` и клику вне меню.
- Галерея с фильтрами «Все / Свадьбы / Семьи / Дети» и CSS-grid мозаикой.
- Лайтбокс: стрелки, клавиатура, свайп через Pointer Events, возврат фокуса.
- Ленивая загрузка изображений, `srcset`/`sizes`, явные `width`/`height` — без CLS.
- Анимации появления блоков с поддержкой `prefers-reduced-motion`.
- Слайдер отзывов с автопрокруткой, паузой при наведении и фокусе.
- SEO-мета, Open Graph, favicon в виде inline SVG.
- Дизайн-система: палитра `#faf8f5` / `#1f1d1b` / `#c08573`, Playfair Display + Inter.

### Админ-панель

- Вход по паролю (по умолчанию `admin2025`).
- Загрузка фотографий с автоматическим сжатием до 1200 px по длинной стороне.
- Категория и alt-описание для каждого фото, изменение порядка, удаление.
- Статистика по количеству фотографий и категориям.
- Редактирование трёх тарифов: название, цена, описание, список «что входит».
- Редактирование контактов: город, телефон, email, профиль ВКонтакте.
- Сброс галереи, цен и контактов к исходным значениям.
- Экспорт и импорт `data.json`, экспорт HTML-разметки галереи.
- Живая синхронизация с открытой страницей сайта через `storage`-событие.

## Быстрый старт

Требуется только [Node.js](https://nodejs.org) — для локального сервера. Сборка не нужна.

### Windows

Дважды запустите `start-server.bat`. Откроется админка по адресу:

```text
http://localhost:8000/admin.html
```

### macOS / Linux / вручную

```bash
node server.js
```

Если порт 8000 занят, сервер автоматически выберет следующий свободный и напишет адрес в консоль.

### Просмотр сайта

```text
http://localhost:8000/
```

> Важно: открывайте сайт и админку по `http://`, а не как файлы `file://`. Браузер делится `localStorage` только между страницами одного адреса — так изменения из админки гарантированно попадают на сайт.

## Как пользоваться админкой

1. Откройте `http://localhost:8000/admin.html`.
2. Войдите с паролем `admin2025`.
3. **Галерея** → «Добавить фото»: выберите изображение, категорию и alt-описание.
4. **Цены** → измените стоимость, описание и список услуг → «Сохранить цены».
5. **Контакты** → обновите город, телефон, email и ВК → «Сохранить контакты».
6. Откройте или обновите сайт — данные подставятся автоматически.

Пароль хранится в исходниках (`admin.html`, константа `PASSWORD`) и предназначен только для демонстрационной защиты. Для реального ограничения доступа нужен бэкенд или serverless-функция.

### Где хранятся данные

| Ключ `localStorage` | Содержимое |
| --- | --- |
| `akimov_photos` | Массив фотографий: `src`, `category`, `alt`, размеры, `span` |
| `akimov_pricing` | Тарифы и их описания |
| `akimov_contacts` | Город, телефон, email, ВК |
| `akimov_admin` (`sessionStorage`) | Флаг входа в админку |

Данные привязаны к браузеру и устройству. Чтобы изменения увидели все посетители, экспортируйте `data.json` и положите его рядом с `index.html` на хостинге.

## Публикация на GitHub Pages

1. Запушьте репозиторий на GitHub.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch** → ветка `main` → папка `/ (root)`.
4. Сохраните настройки и дождитесь публикации.

После деплоя админка доступна по адресу `https://<username>.github.io/<repo>/admin.html`.

Чтобы обновления из админки увидели все посетители:

1. Внесите изменения в админке на опубликованном сайте.
2. Откройте **Публикация → Скачать data.json**.
3. Замените файл `data.json` в репозитории скачанным и сделайте коммит.

Пока `data.json` нет, сайт использует фотографии и тексты, зашитые в `index.html`. Файл опционален: без него всё тоже работает, просто изменения остаются в браузере владельца.

Чтобы проверить, как обновлённый сайт выглядит для нового посетителя, откройте его в приватном окне — там нет данных из `localStorage` вашей админки.

### Другие статические хостинги

Проект подходит для Netlify, Vercel, Cloudflare Pages, GitHub Pages и любого обычного статического хостинга: достаточно загрузить файлы репозитория. Серверная часть не требуется.

## Формат `data.json`

```json
{
  "photos": [
    {
      "id": 1,
      "src": "img/image (1).jpeg",
      "category": "weddings",
      "alt": "Свадебная церемония в Москве",
      "width": 1024,
      "height": 1024,
      "span": 34
    }
  ],
  "pricing": {
    "love-story": {
      "name": "Love-story",
      "price": "12 000 ₽",
      "desc": "Описание тарифа",
      "includes": ["1–2 часа съёмки", "40–60 обработанных фото"]
    }
  },
  "contacts": {
    "city": "Москва",
    "phone": "+7 (900) 000-00-00",
    "email": "hello@example.com",
    "vk": "https://vk.com/username"
  }
}
```

Фотографии, загруженные через админку, хранятся в `src` как base64 (`data:image/jpeg;base64,...`). Это позволяет работать без бэкенда, но увеличивает размер `data.json`.

## Настройка

- **Цвета и типографика** — CSS-переменные в начале `style.css`.
- **Шрифты** — подключение Google Fonts в `index.html` и `admin.html`.
- **Пароль админки** — константа `PASSWORD` в `admin.html`.
- **Исходные фото, цены и контакты** — константы `DEFAULT_PHOTOS`, `DEFAULT_PRICING`, `DEFAULT_CONTACTS` в `admin.html`.
- **Портрет фотографа** — замените `image.jpeg`.
- **Фотографии галереи** — замените файлы в `img/` или загрузите новые через админку.

## Ограничения

- `localStorage` ограничен примерно 5 МБ на домен — обычно это 20–25 сжатых фотографий.
- Изменения в админке по умолчанию видны только в том браузере, где их внесли. Для публикации всем посетителям нужен экспорт `data.json`.
- Пароль админки хранится на клиенте и не является полноценной защитой.
- Форма заявки на сайте — заглушка с `alert`. Для приёма заявок подключите Formspree, Netlify Forms, Getform или собственный API.
- Публичная часть не требует сборки и работает на статическом хостинге; `server.js` нужен только для локальной проверки.

## Доступность и производительность

- Контраст текста и элементов управления, видимый `focus-visible`.
- Кликабельные области не меньше 44×44 px.
- ARIA-атрибуты для меню, табов, лайтбокса, слайдера и форм.
- Уважение `prefers-reduced-motion`.
- Ленивая загрузка, `decoding="async"`, фиксированные размеры изображений.
- Отсутствие сторонних JS-библиотек и сборщиков.
